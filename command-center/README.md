# Quantus Muse command center

Interactive briefing room for the Quantus protocol: emission walk, difficulty retarget, signature budget, and miner concentration, plus the 47-instrument catalog.

This directory is a TanStack Start app. It does not replace the GitHub Pages site in `pages/`.

```bash
cd command-center
npm install
npm run dev
```

Snapshot figures are the Oct 3, 2026 indexer snapshot in `src/muse/snapshot.json`. Emission and retarget math is integer-exact.
