🔍 Source-verified

Every flag, alias, default, conflict rule, and required field was read field-by-field from the real CLI source: Quantus-Network/quantus-cli at rev 531a932 (2026-10-01). Commands that don't exist upstream don't exist here.

🔑 No password field, on purpose

The CLI refuses passwords on the command line. Use QUANTUS_WALLET_PASSWORD, QUANTUS_WALLET_PASSWORD_<NAME>, or --password-file — the forge never asks for your secrets.

⚠️ Validation ≠ guarantee

The forge checks formats, ranges, conflicts, and required flags against the flag map. It cannot check chain state — balances, membership, or whether a proposal ID exists. Read the notes under each command.

Install & password guide

Install the CLI

cargo install quantus-cli
# or build from source:
git clone https://github.com/Quantus-Network/quantus-cli
cd quantus-cli && cargo build --release

The binary is named quantus. Requires Rust 1.89+ and a running node (local default ws://127.0.0.1:9944) for chain commands.

Unlocking wallets safely

export QUANTUS_WALLET_PASSWORD='…'
# per-wallet:
export QUANTUS_WALLET_PASSWORD_MAIN='…'
quantus wallet view --name main

Never pass a password as a flag — the CLI rejects it. Non-interactive scripts use --password-file <path>.
