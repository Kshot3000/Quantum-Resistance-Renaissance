Methodology

How these numbers are made

  • Source. The public Subsquid indexer at sqm.quantus.com/v1/graphql — the same backend as the official explorer. The indexer allowlists only explorer.quantus.com / quantus.com for browser CORS, so this page reads a same-origin snapshot baked by a server-side script (scripts/fetch-whale-data.mjs) instead of querying live.
  • Units. 1 QTC = 1012 planck, verified against the runtime emission formula (see the Emission Lab). All QTC figures are exact BigInt conversions, not floats.
  • Supply. “Indexed supply” = Σ(free + reserved + frozen) across all indexed accounts. “Locked” = unclaimed genesis vesting (vesting total − claimed), which sits in the block-1 allocation account. “Circulating” = indexed supply − locked.
  • Honest limits. Balances move every block (~12s); the snapshot is a still photo, time-stamped above. Bracket aggregates are exact indexer counts; the Gini is an estimate. Nothing here is investment advice — concentration ≠ intent.
