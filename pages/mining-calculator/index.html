Start mining in six steps

Condensed from the official Quantus mining guide — follow it for the full detail.

  1. Get a Quantus wallet. It holds your funds and spends mining rewards.
  2. Generate a wormhole keypair. Rewards accumulate at wormhole addresses only: ./quantus-node key quantus --scheme wormhole --words. Back up the 24-word phrase.
  3. Download node v1.0.1+ and a matching miner from the Quantus-Network GitHub releases (chain + quantus-miner). macOS or Linux x86_64 — there is no native Linux ARM64 miner.
  4. Start the node on mainnet (not planck — that testnet is retired):
    ./quantus-node --chain mainnet --validator --miner-listen-port 9833 --rewards-inner-hash <your-inner-hash> --sync full
    Wait for full sync (Idle at the tip) before mining — blocks found while syncing are orphans and earn nothing.
  5. Start the miner in a second terminal:
    ./quantus-miner serve --cpu-workers 4 --gpu-devices 0 --node-addr 127.0.0.1:9833
    Newer node/miner pairs need the auth + TLS-pin flags — the guide's automated script wires them: curl -fsSL https://docs.quantus.com/scripts/quantus-mining.sh
  6. Watch rewards land at your wormhole address in the wallet app — no claiming step. Monitor at telemetry.quantus.cat or localhost:9615/metrics.

Read before you ape in

  • Estimates, not income. Difficulty retargets, luck variance, stale/orphan blocks, and pool fees all move real results away from the math above.
  • No public QTC price exists yet. NEAR Intents is announced as the first trading venue with no listing date — any revenue figure here uses your assumed price.
  • Defaults come from the chain, not a calendar. Network hashrate, supply, and block pace default to the builder's hourly chain snapshot — difficulty-implied hashrate, total issuance, and the observed block pace rather than the 12s target. If the snapshot can't load, the page falls back to the dated Oct 2, 2026 capture and labels it. (Before Oct 2, 2026 this page pre-filled a 10 GH/s example rate that overstated a default rig's estimate roughly 5,500-fold; the snapshot defaults fixed that.)
  • Mainnet is real money. Back up your seed phrase, keep miner auth files private, and never expose the miner port (9833) to the internet.
