Is this QTC address real?

Paste any address. The toolkit decodes the SS58 payload, re-computes the blake2b checksum, and tells you exactly what it is — prefix, key bytes, and verdict. No network calls, no wallet, nothing leaves your browser.

Encoding is pure math: base58(prefix ‖ key ‖ checksum), checksum = first 2 bytes of blake2b("SS58PRE" ‖ prefix ‖ key).

How a QTC address is built

Quantus uses the SS58 address format (the Substrate standard) with network prefix 189 — set in chain_spec.rs. That prefix is why every mainnet address starts with qz.

prefix bytes111 · 64= 189
32-byte account key32 bytes
checksum2 bytes
Checksum
blake2b-512 of "SS58PRE" + prefix + key, first 2 bytes. Any typo breaks it.
Base58
Bitcoin-style alphabet — no 0, O, I, l. Ambiguous characters are rejected.
Wrong network?
A valid SS58 address with a different prefix (e.g. Polkadot's 0) is flagged, not mistaken for QTC.
