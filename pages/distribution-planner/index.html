Command reference

quantus batch config --limitsPrint the chain's live safe/recommended batch limits — match the planner's batch size to it.
quantus batch send --from <wallet> --batch-file transfers-batch-1.jsonSubmit one batch. Amounts are raw plancks; the CLI validates them again before signing.
quantus batch send --from <wallet> --batch-file f.json --tip 0.1Optional tip (QTC) per batch extrinsic to prioritize inclusion.
Safety

Read before you run

  • Atomic batches. The CLI builds utility.batch_all: every transfer in a batch succeeds, or the whole batch fails — no partial payouts. (Asserted by the CLI's own unit test.)
  • Test with batch 1. Pay the first batch alone, verify it on the explorer, then run the rest.
  • Never re-run blind. A timed-out or failed submission may still have landed on chain. Check the sender's nonce / the explorer before re-running, or recipients get paid twice.
  • No passwords on the command line. The CLI reads wallet passwords from a hidden prompt or --password-file — never paste one into a terminal command or a file you share.
  • Verify checkphrases out of band. Confirm each recipient's five-word phrase with them directly before the run — the phrase is the last line of defense against a pasted wrong address.
  • This page is a planner. It never signs, never submits, never sees your keys. Execution happens in your own quantus CLI.
