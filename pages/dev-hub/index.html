Unit converter — exact to the planck

QTC uses 12 decimals: 1 QTC = 1012 plancks (runtime UNIT). Math runs on BigInt — no floating-point dust. The existential deposit is 0.001 QTC (1,000,000,000 plancks).

Accounts & keys

The part of Quantus that breaks Substrate muscle memory: accounts are keyed by post-quantum ML-DSA, not sr25519.

Address format

  • SS58 prefix 189 — every Quantus address starts with qz… (qznY8nwuvWcCCVys4da1oQdysyh8YUZYRjRqgk3S8Wos8kbau)
  • 32-byte public key + 2-byte blake2b checksum, base58-encoded (standard SS58)
  • Human-readable checkphrases come from qp-human-checkphrase — the same encoding SafeSend verifies
Open the Address Toolkit →

Key type

  • ML-DSA (Dilithium family) keys — ML-DSA-65 / ML-DSA-87 since the genesis block
  • Signatures are ~2.6–4.6 KB; that's why Quantus transactions are ~7 KB and need native aggregation
  • Do not generate keys with polkadot-js's sr25519/ed25519 keyring — create them in the official wallet or quantus-cli
Open the SafeSend Lab →

Balance rules

  • Existential deposit: 0.001 QTC — accounts below it are reaped
  • Use balances.transferKeepAlive so you can't accidentally kill your own account
  • Reversible transfers (SafeSend) hold funds on a delay — the pallet can recover_funds to the sender if the receiver never claims
